Section 10

From molecular dynamics to a latent map

A machine-learning model never sees atoms. It sees a table of numbers. This section builds that table from a small molecular-dynamics simulation you can run in your browser, so you can see exactly where each ML concept comes from in the physics.

1 · MDIntegrate Newton’s equations at a set temperature
2 · SnapshotsEquilibrate, then record frames
3 · DescriptorTurn each frame into numbers (e.g. local volume)
4 · MatrixRows = conditions, columns = features
5 · Scale + DRNormalise 0–1, then PCA / t-SNE / UMAP

Step 1 — Run the molecular dynamics

A 2-D Lennard-Jones solid (64 particles, periodic box, velocity-Verlet, simple velocity-rescaling thermostat). Raise the temperature and watch the lattice lose order. Colour = local free-area proxy (area of a hexagon built from each particle’s 6 nearest neighbours; it stands in for the Voronoi cell volume).

Step 2 — Sweep temperature and build the data matrix

For each of 8 temperatures the script equilibrates, records 25 frames and averages a histogram of the local free-area of all particles. One temperature becomes one row of 24 numbers. Then it applies global MinMax and runs PCA — the same pipeline used on the polymer data.

Press the button.
How to read the right plot. ψ6 is the classic order parameter: you have to know to look for six-fold order. PC1 is found with no physical knowledge at all. If the two curves follow each other, the unsupervised method has rediscovered the physics.

What is different from the polymer study

Identity of the features. In the chain data, column j is always the same backbone atom, so a row is a fingerprint of that chain at one temperature. Fluid particles here are interchangeable, so we describe each system by a distribution (histogram) instead. Always ask what a column means before reading a latent map.

Finite size. With 64 particles the order loss is a smooth crossover, not a sharp jump. A latent-map “transition” from a small simulation can be a smooth bend; locating it precisely needs more atoms, finer temperature steps, and a physical check such as volume–T or energy–T.

Thermostat. Velocity rescaling is the simplest way to hold T. Production MD uses Nosé–Hoover or Langevin; the ML side does not change.

This is a teaching model (2-D, reduced units). Do not read its transition temperature as a real material property.
